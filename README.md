# Business-Process-Focused-Payroll-Validation-Audit-Project
Payroll Validation & Audit Dashboard 💜

📊 Project Overview

This project focuses on validating payroll calculations and identifying discrepancies in employee salaries by combining SQL and Power BI.

🔍 Key Features

- Rebuilt payroll logic (HRA, Tax, PF)
- Used SQL to store and query payroll data
- Compared expected vs actual salary
- Created Error Detection system
- Built KPIs like Total Salary, Average Salary, and Error Rate using DAX

🛠 Tools Used

- SQL (MySQL)
- Power BI
- DAX
- Excel

🧠 SQL Work

- Created payroll table
- Inserted employee salary data
- Queried salary, bonus, and deductions
- Validated calculations using SQL queries

📈 Key Insights

- Payroll discrepancies detected due to incorrect tax logic
- Higher HRA leads to higher calculation errors
- System needs correction in taxable income formula

📂 Files Included

- Power BI Dashboard (.pbix)
- Dataset (.xlsx)
- SQL Queries (.sql)
- Dashboard Screenshot
